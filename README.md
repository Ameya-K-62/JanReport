# JanReport: AI-Assisted Citizen Journalism Platform

A full-stack platform for reporting, reviewing, moderating, and discovering local news with AI-assisted content analysis, sentiment analysis, analytics, and location-based visualization.

## Overview
JanReport is a full-stack citizen journalism platform that enables users to submit and discover local news through a structured reporting, review, moderation, and publication workflow. The platform combines a React and TypeScript frontend with a Node.js and Express.js backend, MongoDB for data management, and AI/NLP services for content analysis. It also provides OCR-based information extraction, interactive maps, analytics dashboards, image management, and role-based moderation.

## Key Features
- Local news reporting with title, description, category, location, and supporting images.
- User registration, login, JWT authentication, password hashing, and role-based authorization.
- Moderation workflow for reviewing, approving, rejecting, and providing feedback on reports.
- AI-assisted content analysis and authenticity assessment.
- NLP-based sentiment analysis and incident severity estimation.
- OCR-based text and location information extraction from images.
- Interactive map visualization of location-based news reports.
- Analytics dashboard with charts and data visualization.
- Cloud-based image storage and media management.
- Email notifications for moderation-related events.

## Technology Stack
**Frontend:** React, TypeScript, Vite, Tailwind CSS, React Leaflet, Leaflet, Recharts, Axios  
**Backend:** Node.js, Express.js, MongoDB, Mongoose, REST APIs, JWT, bcrypt, Multer, Express Validator, Nodemailer  
**AI & NLP:** Artificial Intelligence, Natural Language Processing, Generative AI, Large Language Models, Groq API, Hugging Face, DistilBERT, Sentiment Analysis  
**External Services:** Cloudinary, OCR.Space, OpenStreetMap Nominatim, Hugging Face Inference API, Groq API
